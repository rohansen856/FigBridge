## Annotate your code

1. In Figma, right-click a frame and choose **Copy link to selection**.
2. In your editor, put the cursor above a class or function.
3. Run **FigBridge: Insert Figma Reference…**.

```dart
/// @figma F7KQ9M2X4P6D
class CheckoutScreen extends StatelessWidget { … }
```

Hover the ID to see the design. Open the **FigBridge** view in the Activity Bar for mapping health.
