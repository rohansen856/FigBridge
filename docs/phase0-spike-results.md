## Decisions recorded

- **ADR-014:** no code reuse from prior art. vlint is unlicensed. Frame2Code and Code Connect are not worth the dependency.
- **ADR-015:** the Claude event spool lives in a per-user state directory, not `.figbridge/` in the repo. This prevents forged events from being committed and needs no `.gitignore` changes.
- **ADR-016:** tree-sitter WASM for TS/TSX/JS (prebuilt) and Dart (self-built, pinned).
- **ADR-017:** Claude integration ships as a Claude Code plugin (MCP server + hooks + skill) in a local marketplace bundled with the extension. FigBridge never edits `.mcp.json`, settings or `CLAUDE.md`.
- **ADR-018:** a successful Figma mutation with a known file marks **every** preview of that file stale. Edits to children change ancestors' renders, and ancestor IDs are unknown. Node IDs only decide which refs are listed first.
- **ADR-019:** the annotation directive is `@figma <ID>` (the spec's `@figma-ref` is superseded). Generated IDs always contain a letter other than `E`, so YAML never reads them as numbers. The loader also restores numeric-looking keys from the source text.
